正式サマリーはバッチ完了を必須とするため、完了したbatch 0の40件だけが `OK`、残り160件は `失敗` と記録されています。この160件すべてで地図描画が失敗したという意味ではありません。途中まで取得できたbatch 1〜4には描画成功レコード59件とタイムアウト4件が含まれ、残り97パターンはbatch中断により未実行です。部分結果を200件合格として扱わないための保守的な集計です。

タイムアウトは金沢 H0、旭川 H3、長野 H3、高知 H1 で発生しました。エラー表示時に地図の描画確認用feature countが取得できず、原因をタイルサーバー、ネットワーク、Simulator側のどれかに特定できていません。失敗分を成功として扱わず、結果を未完了としています。別runでも柏・難波などで同じ読み込みタイムアウトが発生しました。

完了した個別レコードでは、地図中心・ズーム、道路、線路、建物、施設アイコン、確認済み路線色、新幹線geometry、表示ラベルの一部をMapLibreの描画feature queryで検査しました。これはタイル一枚ごとの完全性、表示色の地理的正確性、施設情報自体の正しさ、すべての文字の視認性を保証するものではありません。施設・路線データの根拠はOSM監査記録で別に確認してください。
